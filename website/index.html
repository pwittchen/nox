~/nox $ ls features/

      
Fast. Native. Quiet.

      

        

          01
          
Native to the metal

          
Drawn by GPUI on Metal, text shaped by Core Text, menus by AppKit. A usable prompt in well under 150 ms.

        

        

          02
          
Splits & tabs, like iTerm

          
Split right with ⌘D, below with ⌘⇧D, nest them as deep as you like. Tabs on top, bottom or in a sidebar.

        

        

          03
          
Workspaces

          
Named groups of tabs per project, switched instantly with ⌘P. Each keeps its own tabs, splits and agents.

        

        

          04
          
Comes back after a reboot

          
Quit, restart, reboot: every workspace returns with its tabs, splits and working directories — and every agent resumes its conversation.

        

        

          05
          
Smooth everything

          
Pixel-precise scrolling with trackpad momentum. Live window resize without flicker, stretching or garbled output.

        

        

          06
          
Proven emulation core

          
VT parsing, grid and scrollback from alacritty_terminal. Rendering, UI and the agent features are nox's own.

        

        

          07
          
18 themes, 9 mono fonts

          
Catppuccin, gruvbox, Nord, Tokyo Night, Kanagawa, Rosé Pine and more, light & dark. JetBrains Mono by default; Fira Code, Hack, Commit Mono and friends bundled.

        

        

          08
          
Find, links, prompts

          
Search the scrollback with ⌘F, open links with a click, jump between prompts with ⌘↑ ⌘↓, copy the last command's output with ⌥⌘C.

        

        

          09
          
Nothing phones home

          
No account, no telemetry, no built-in AI. nox runs no model and sends nothing anywhere. It hosts agents; it isn't one.

nox — agent CLI


# every pane has `nox` on its PATH and its own identity
$ nox name backend
$ nox status working -m "refactoring"
$ nox msg reviewer "feat/x is ready"
$ nox wait backend          # block until its turn ends
$ nox claim src/parser/ -m "rewriting"
✗ claimed by backend: rewriting # exit 3
$ nox spawn --split right -- cargo test
pane 7
$ claude mcp add nox -- nox mcp # same ops as MCP tools

        

      

      

        
Knows the state. Working, needs input, idle, exited — from hooks, OSC notifications, titles or activity. Shown in tabs, pane headers and the agents panel.

        
Taps you on the shoulder. A sound and a notification when an agent needs you and nox isn't in front. ⌘J jumps straight to it.

        
Cooperation, not chaos. Messages, waits and advisory file claims over a local Unix socket. Never a network port, always visible to you.

~/nox $ $EDITOR ~/.nox/config.toml

      
Tuned in plain text.

      
One TOML file, applied live on save. Edit it by hand or in the Settings window (⌘,) — both stay in sync, and your comments survive.

      

        
~/.nox/config.toml


[ui]
theme = "nox"                 # or any of the 17 bundled, or ~/.nox/themes/
mode = "system"               # "system" | "light" | "dark"
dim_inactive_panes = 0.15

[tabs]
position = "top"              # "top" | "bottom" | "left"
title = "auto"                # "auto" | "cwd" | "process"

[font]
family = "JetBrains Mono"
size = 14
line_height = 1.0             # × natural line height

[agents]
restore = "resume"            # resume conversations on relaunch
keep_awake = true             # no sleep while an agent works
scope = "workspace"           # a workspace is a team

[agents.claude]
command = "claude"
resume = "claude --resume {session}"
